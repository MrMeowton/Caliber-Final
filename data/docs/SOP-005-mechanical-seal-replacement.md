# SOP-005 Pump Mechanical Seal Replacement — FICTIONAL
1. Switch to the standby pump if available; isolate and drain the pump; apply LOTO (SOP-006).
2. Confirm the replacement seal cartridge part number matches the pump datasheet.
3. Remove coupling, bearing housing and old seal cartridge; inspect shaft sleeve for scoring.
4. Install the new cartridge; set and lock the setting plates per vendor instructions.
5. Flush the seal plan lines before start-up; check for leaks during the first 4 h.

# SOP-007 Critical Spare Part Request and Emergency Purchase — FICTIONAL
1. Check stock in the ERP by part number and criticality class (A = failure stops production).
2. If a class-A part is below minimum stock, raise a purchase requisition the same day.
3. Emergency purchase (expedited delivery) requires plant manager approval; typical premium 30–50% of unit cost.
4. Lead times for class-A rotating-equipment parts are typically 3–6 months; plan ahead from condition-monitoring alerts.
